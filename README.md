# ShiwakeFiler（シワケファイラー）

**動画・画像・PSD・PDFプレビュー付きの2ペインファイラー（Windows用）**

大量の動画や画像、PSD、PDFを「見ながら仕分ける」ためのツールです。
ファイルを選ぶとすぐにプレビューが表示され、動画なら横に並んだサムネイルで中身をひと目で確認できます。
キーボードだけで、マーク・移動・コピー・リネーム・削除まで行えます。

## 主な機能

- **2ペインファイラー**：左右のペインのあいだで、ファイルやフォルダを移動・コピーできます
- **プレビュー**：動画を選ぶとすぐに再生。シークバーはクリックした位置へジャンプします
- **画像プレビュー**：静止画は枠に収めて表示します（スマホ写真の向きも自動で補正、GIFアニメも再生）
- **PSDプレビュー**：Photoshopファイルの統合画像を表示します（※下記の注意を参照）
- **PDFプレビュー**：ページを表示し、全ページの縮小画像を横に並べます。クリックや Ctrl+←→ でページ送り
- **サムネイル帯**：動画全体から12コマを切り出して横に並べ、クリックでその位置へジャンプします
- **デスクトップへのショートカット**：一覧の先頭に常に「デスクトップ」があり、すぐ移動できます
- **リネーム**：拡張子を残したまま名前を変えられます
- **マーク操作**：複数のファイルをまとめて移動・コピー・削除できます
- **ごみ箱へ削除**：完全には消さず、ごみ箱へ移すので安心です
- 大きいファイルのコピーや別ドライブへの移動には進み具合を表示し、途中で中止もできます
- 日本語のファイル名・フォルダ名に対応しています

## ダウンロード

[Releases](../../releases) から最新版のZIPをダウンロードし、展開した中の `ShiwakeFiler.exe` を実行してください。
Pythonなどのインストールは不要です。

> 初回起動時にWindowsの「PCを保護しました」という画面が出ることがあります。
> 「詳細情報」→「実行」で起動できます（署名のない個人製作アプリのため表示されます）。

## キー操作

### ファイラー

| キー | 動作 |
|---|---|
| ↑ ↓ | 選択 |
| ← → / Tab | 左右のペインへ移る |
| Enter / ダブルクリック | フォルダに入る（ファイルの場合はリネーム欄へ） |
| Backspace / Alt+↑ | 上のフォルダへ |
| Alt+← / Alt+→ | 戻る／進む |
| Ctrl+L | アドレス欄へ（パスを貼り付けてEnter） |
| F5 | 再読み込み |

### ファイル操作

マークがあればマークしたもの、なければカーソルのある行が対象になります。

| キー | 動作 |
|---|---|
| Space | マーク（次の行へ進む） |
| Ctrl+A | すべてマーク／すべて解除 |
| M | 反対側のペインへ移動 |
| C | 反対側のペインへコピー |
| K | フォルダを作成 |
| D / Delete | ごみ箱へ移動（確認あり） |
| R / F2 | リネーム（Enterで確定／Escで取り消し） |
| L | ドライブを選ぶ |
| O | 反対側のペインを同じフォルダにする |

### プレビュー

| キー | 動作 |
|---|---|
| P | 再生／一時停止 |
| Ctrl+← / Ctrl+→ | 5秒戻る／進む |
| Ctrl+Shift+← / Ctrl+Shift+→ | 1秒戻る／進む |
| Ctrl+← / Ctrl+→（PDF） | 前／次のページ |

画面上部の「対応ファイルのみ」「隠しファイル」「選択で自動再生」「ミュート」のチェックで、表示や再生の動きを切り替えられます。

## 対応している形式

- **動画**：mp4 / mkv / avi / mov / wmv / m4v / mpg / mpeg / ts / m2ts / mts / webm / flv / 3gp / vob
- **画像**：jpg / jpeg / jfif / png / gif / bmp / webp / tif / tiff / ico / tga / svg / psd
- **文書**：pdf

**PSDについての注意**：Photoshopで「互換性を優先」をオンにして保存したPSD（初期設定）が対象です。レイヤーごとの表示はできません。CMYKのPSDは簡易的にRGBへ変換するため、色味が実物と少し異なります。16bitのPSDやPSB形式は表示できない場合があります。

## ソースから実行する

Python 3.10以上が必要です。

```
pip install -r requirements.txt
python shiwake_filer.py
```

## exeを作る

Windows上で `build_exe.bat` をダブルクリックすると、`dist\ShiwakeFiler` フォルダにexe一式ができます。
このフォルダをZIPにすれば配布用になります。
